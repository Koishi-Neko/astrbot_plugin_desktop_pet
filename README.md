## 特性

一只直接住在你 Windows 桌面上的 Live2D 小家伙。看你心情，我们有两种玩法：

| | AstrBot 模式（火力全开版） | 独立模式（轻量级懒人版） |
| --- | --- | --- |
| 大脑 | AstrBot（webchat 管道） | 任意 OpenAI 兼容大模型（云端 API / 本地 Ollama） |
| 人格 / 历史 | 会话级人格 + 平台历史，还内置了长期记忆（向量召回 + 反思） | 设置面板随便填段人格文本，带个当前会话记忆 |
| 日语配音 | SBV2 语音合成，逐句播放 + 嘴形同步 | 也是一样（自己配个 TTS 地址就好） |
| 需要部署 | AstrBot 跑起来（Docker / 本机） | 啥都不用，5 分钟直接上手 |

- **Live2D 桌面立绘**：无边框透明置顶小窗。带情绪表情、能戳一戳互动、视线会跟着鼠标跑、没事干会自己待机玩耍、放久了还有特殊演出。
- **多模型热切换**：自带了桃濑日和 + 智乃/智乃Q版（本地），右键菜单点一下瞬间切换，还会记下你的偏好；当然你也可以把你珍藏的任意 Cubism 3~5 模型**直接拖进去**就能用（支持文件夹 / .model3.json / .zip 格式）。
- **打字机气泡 + 输入框**：回复如果带【情绪】标签，表情会自动跟着变。中文气泡，如果你高兴还能加上日语逐句配音。
- **语音输入**：点输入栏旁边那个麦克风，说话 → 本地 ASR（whisper @ Intel NPU）识别 → 自动发出去，连敲键盘都省了；开关和识别地址全在控制页配。
- **主动搭话**：大半夜催你睡觉、离开一会儿回来会跟你打招呼、坐久了还提醒你起来走走；它还会偷偷看你的桌面，看到有趣的东西会跟你搭话（放心，不想被看的东西可以加黑名单，微信/QQ/Office 这些默认不看）。
- **内置长期记忆**（AstrBot 模式）：小家伙自己就会记事，不用装别的记忆插件——LLM 负责定期把聊天反思成记忆，问问题时按向量相似度想起来，每天凌晨还会写一篇桌宠日记；控制页里能浏览、增删、试召回，如果你之前在用 LivingMemory，还能一键把旧记忆搬过来。
- **WebUI 控制页**：如果你用 AstrBot 模式，服务端的配置我都给你做了全图形化，填完保存立刻生效。

## 快速开始
<a id="快速开始"></a>

### 路线 A：5 分钟速通（无 AstrBot）

1. 去 [Releases](https://github.com/Koishi-Neko/astrbot_plugin_desktop_pet/releases) 抓个 Windows 便携版下来（zip 解压直接用，或者你想用 NSIS 安装包也行）。
   > 如果第一次打开，Windows 那个 SmartScreen 弹出来说「已保护你的电脑」：别慌，单纯是我没钱给 exe 买代码签名，点「仍要运行」就行。
2. 对着立绘右键 → **设置 → 运行模式 → 独立模式**，填好这三个：
   - 模型地址（只要兼容 OpenAI 格式就行，比如 `https://api.deepseek.com/v1`；如果你跑了本地 [Ollama](https://ollama.com)，就填 `http://localhost:11434/v1`）
   - 模型 API Key（本地 Ollama 你就随便瞎敲点什么）
   - 对话模型名（比如 `deepseek-chat`）
3. 戳一下「测试连接」，看到模型理你了就是成功了。双击立绘，开聊！

日语配音（可选）：要是你想听配音，你得在自己电脑上跑个 [Style-Bert-VITS2](https://github.com/litagin02/Style-Bert-VITS2)，具体看[独立模式](#独立模式)底下的说明。

### 路线 B：AstrBot 究极形态（带人格 / 记忆 / QQ 联动）

前提：你已经把 AstrBot v4 跑起来了，而且能进 WebUI（默认是 `http://localhost:6185`）。不会的话去翻 [AstrBot 官方文档](https://docs.astrbot.app/)。

1. **安装插件**：WebUI → 插件 → 安装插件 → 填我这个仓库地址 `https://github.com/Koishi-Neko/astrbot_plugin_desktop_pet`。
   > 注意下，插件走的是 AstrBot 自己带的 webchat，你不用去「平台」配置里再折腾一遍。
2. **搞个 API Key**：WebUI → 设置 → API Key → 新建，把 **plugin、chat、file** 这三个权限全勾上，复制存好。
3. **下载桌宠壳子**：同样去 [Releases](https://github.com/Koishi-Neko/astrbot_plugin_desktop_pet/releases) 拿 Windows 版（NSIS 安装包或者便携 zip 都行）。
4. **初次连接**：右键立绘 → 设置，把你的 AstrBot 地址填进去（直接填 `http://localhost:6185` 就好，它自己会补全后面的），再贴上刚才的 API Key。点「测试连接」——只要 plugin / chat / file 三个都亮绿灯，搞定。双击立绘，开始聊天。
5. **（选做）捏个人格**：WebUI → 插件 → astrbot_plugin_desktop_pet → 控制页 → 桌宠人格，下拉选好保存（不选就用 AstrBot 的默认设定）。对了，如果小家伙还没说过话，系统里没这个会话，你得先发条消息逗逗它，再回来设。

至于服务端那些花里胡哨的配置（TTS、主动聊天、看桌面、主人身份、QQ 配音），都在 **WebUI → 插件 → astrbot_plugin_desktop_pet → 控制页** 里，配完保存当场生效。

## 独立模式
<a id="独立模式"></a>

要是你嫌部署 AstrBot 太麻烦，这小家伙也能单飞：**设置面板 → 运行模式 → 独立模式**。这样它就会直接去连任何 OpenAI 兼容的 API（比如云端的 DeepSeek / Kimi，或者你自己跑的 Ollama）。聊天、表情变化、日语配音、主动找你说话、看桌面这些全都照常工作。唯一的妥协就是**它记不住以前的事情了**（长期记忆是 AstrBot 模式下插件内置的能力，独立模式只能记住这次打开后的聊天）。

| 能力 | AstrBot 模式 | 独立模式 |
| --- | --- | --- |
| 聊天 / 情绪标签 / 表情切换 | ✅ | ✅ |
| 日语配音（需本机跑个 SBV2） | ✅ | ✅（把 TTS 地址填上就行） |
| 语音输入（需本地 ASR 服务） | ✅（在控制页配开关和地址） | ✅（默认连 15055，想改去改 config.local.json） |
| 主动对话 / 桌面感知 | ✅ | ✅（截图直接传过去，视觉模型可以和对话模型一样，也可以分开配） |
| 会话人格 | 靠 WebUI 控制页 | 设置面板里的「人格」框直接填（空着就用我内置的默认版） |
| 长期记忆 | ✅（插件内置：向量召回 + 反思 + 日记） | ❌（V1 里先鸽了） |
| 配置都在哪 | WebUI 控制页 | 设置面板 / 或者手改 `config.local.json` |
| 各种状态监控 | ✅ | ❌ |

想要配置独立模式，去设置面板的「独立模式」那块，或者直接刚 `config.local.json` 里面的 `standalone` 节点：

```json
{
  "mode": "standalone",
  "standalone": {
    "llm_base_url": "https://api.deepseek.com/v1",
    "llm_api_key": "你的模型 API Key",
    "llm_model": "deepseek-chat",
    "persona": "选填，这会覆盖内置的默认人格",
    "tts_url": "http://localhost:5000",
    "scene_model": "选填，让它看桌面的视觉模型，不填就直接用上面那个对话模型"
  },
  "asr": {
    "url": "http://127.0.0.1:15055"
  }
}
```

> 想换回 AstrBot 模式？去设置面板把模式下拉菜单拨回去就行。两种模式各玩各的，互不干扰，随时切换。

**关于独立模式的日语配音**：你得在本地搭个 Style-Bert-VITS2（SBV2）。如果是本机（WSL 部署）的 SBV2 监听了 `127.0.0.1:5000`，靠 WSL2 的 localhost 转发，你在 Windows 里直接填 `http://localhost:5000` 就能让它开口（2026-08-03 我们把后端容器化扬了之后，再也不用管什么回环网络桥接了）；要是 TTS 地址空着，它就会很乖地退化成只有文字气泡。

## 进阶玩法
<a id="进阶玩法"></a>

<!-- 控制页截图：docs/assets/control-page.png（控制页 + 桌宠同框） -->
![WebUI 控制页与桌宠](docs/assets/control-page.png)

### TTS 日语配音（非必须，但很爽）

想让桌宠开口说日语，你得自己折腾一下 [Style-Bert-VITS2](https://github.com/litagin02/Style-Bert-VITS2)，并准备好声线模型：

1. 把 SBV2 跑起来，记好它的服务地址（如果 AstrBot 在 Docker 里，SBV2 在 WSL 宿主机上，通常是 `http://172.18.0.1:5000`）。
2. 在插件控制页的「TTS 语音配置」卡片里，填上这个地址，从下拉框里挑好模型/说话人/风格，把开关打开，保存。
3. 回到桌宠壳子的设置面板，把「语音（日语配音）」开关拨到开。

完事之后，它的回复就会变成「中文气泡 + 逐句念出的日语配音 + 对应的嘴型同步」。如果你在控制页还开了「QQ 日语配音」，它在 QQ 群或私聊里回复时，也会顺手发一条语音过去（要是你的 SBV2 挂了，它会自动只发文字，很靠谱的）。

> `2.7.0-JP-Extra` 系列的模型只能说日语；想让它说中文的话，去另找个标准的三语模型装上。

### 语音输入（本地 ASR，解放双手）

点开输入栏，戳左边那个圆圆的麦克风按钮开始录音（它会像呼吸一样闪红光），说完再点一下，或者直接闭嘴 1.2 秒，它就会自动停下。识别出的字会填进框里，半秒后自动发出去（你要是想反悔，点一下输入框或者敲个键盘就能取消）。录音的时候它会很专注，暂停视线跟随和待机动作。

- **这是什么黑科技**：跑在本地的 whisper（OpenVINO 架构，默认拿你 Intel 的 NPU 算）。它把字认出来发出去之后，走的是完整的对话管线，人格、记忆、情绪、日文配音一个都不会少。
- **怎么跑这服务**：这玩意是个 Windows 本地进程（`tools/asr_server.py`，是个 FastAPI，跑在 `http://127.0.0.1:15055`）。你需要装好 Python 3.12 + `openvino-genai`，还得备好 whisper 模型（`whisper-large-v3-turbo-fp16-ov`，OpenVINO 官方转换那个版本）。第一次启动时 NPU 编译模型大概得卡个 4 分钟，这段时间麦克风按钮是灰的，编译完自己就好了。
- **开关在哪**：如果是 AstrBot 模式，去插件控制页的「语音输入」卡片里配开关和地址（壳子大概 2 分钟内会拉取到最新配置）；独立模式默认就是连 `http://127.0.0.1:15055`，想改就在 `config.local.json` 的 `asr` 块里覆写。
- **有口音怎么办**：可以在设置面板里填个 `initial_prompt`，用来教它认一些特定的词（热词）。如果 NPU 的静态形状管线跑崩了，服务端会自动降级去掉热词再试一次，反正语音输入绝对不会卡死。
- **启动说明**：为了不拖慢你开机，ASR 服务默认是不会跟着桌宠自启的。想用的时候跑一下 `pet_shell/tools/start_asr.ps1`（或者直接双击 `start_asr.vbs` 也行，随便跑几次都不会重复启动；日志在 `asr-npu\asr.log` 里）。不想用了跑 `stop_all.ps1` 就能一起关掉。
- 目前识别锁死了中文（不过你硬说英语它也能给你写下来）；顺带一提，音频全在你本机处理，不传服务器，主打一个隐私安全。

### 主动找你聊 & 偷看桌面

去插件控制页配一下（独立模式去 `config.local.json` 改 `proactive` 块），壳子最多 2 分钟就会更新配置：

- **主动搭话**：半夜 23 点到 2 点你还在动鼠标，它会催你睡觉；离开座位半小时回来，它会问候你；连续坐了两个小时，它会提醒你小心腰椎。这功能全局冷却 45 分钟，而且如果你开了全屏游戏、正在打字或者人不在电脑前，它绝对不会来烦你。
- **偷看桌面 (桌面感知)**：它会按设定好的时间间隔，截一张你**当前最靠前窗口**的图，丢给视觉模型看。要是看到了什么好玩的东西（比如你游戏打出神级操作，或者逛到了什么沙雕网页），它就会自然地跟你搭话；如果啥也没有，它就乖乖闭嘴。**注意，截图是会发给你的 LLM 提供商的**。视觉模型可以在控制页的提示列表里挑，不填就默认用你聊天的那个模型。我给它塞了个「禁止抓取名单」（默认包含微信、QQ、钉钉、Office 这些），只要这些软件在最前面，它就直接跳过不截图。另外，那些独占全屏的游戏它是截不到的，想让它看请开无边框窗口模式。
- **点名看图 (指令感知)**：你也可以直接打字或者语音对它说「看看我的屏幕」或者「我在干嘛」，它会当场截一张最前面的窗口图，连着你的问题一起发给视觉模型。因为你给它下命令的时候焦点肯定在桌宠身上，所以它其实聪明地截了**除了桌宠之外最靠前的那个窗口**。这功能跟自动感知是两码事——哪怕你关了自动看桌面，直接点名它照样会看。不过，它俩共用那个「禁止抓取名单」，要是撞上了名单里的软件，它不会截图，还会开口跟你解释说这玩意不能看。触发看图的关键词你可以在控制页自己加（一行写一个词，要是你说了「别看」「不要看」这种词它会很识相地不截图）。截图失败（比如独占全屏、DRM 保护或者最小化了）它也会老老实实告诉你。对了，语音下令需要语音服务开着，打字下令啥时候都行。

### 换上你老婆/老公的 Live2D 模型

随便找个 Cubism 3 或者 4 的模型，扔进 `pet_shell/src/assets/live2d/chino/` 里，把主文件改名叫 `chino.model3.json`（记得重新构建一下才能生效），就能把默认模型换掉。**注意，模型文件名还有 model3.json 里面引用的路径，必须全是纯 ASCII 字符（别带中文）**。想要让情绪标签正确控制表情，去 `pet_shell/src/app.js` 里找到 `EMOTION_EXPRESSIONS`，按你模型的实际表情名改一下映射。

如果你想同时养好几只随时换：在 `app.js` 里的 `MODELS` 注册表和 `MODEL_PROFILES` 能力档案里各加一行配置（把资源放进 `assets/live2d/<你的模型key>/`），然后右键菜单的「切换模型」里就会多出这个选项。点一下瞬间换人，而且它会记住你的选择。

觉得改代码太麻烦？你也可以**直接把模型上传过去**：直接把模型文件夹或者 zip 包拖到桌宠身上，或者去设置面板里的「上传 Live2D 模型」那手填路径。我们支持文件夹、`.model3.json`，甚至是 `.zip`（支持 Cubism 3~5 的 moc3 格式）。传完之后它立刻就会换上新模型并记住，你以后随时可以在「切换模型」的子菜单里换着玩，或者点个 `×` 把不要的删掉。你上传的这些宝贝都存在 `%LOCALAPPDATA%\com.astrbotpet.shell\models\` 下面，通过壳子里我自己写的一个 petmodel 协议加载。

仓库里我给你塞了个官方免费的示例模型**桃濑日和**（版权许可见模型目录下的 `ReadMe.txt` 和 [官方许可页](https://www.live2d.com/zh-CHS/download/sample-data/)）。你要是用自己弄的模型，注意版权问题，别瞎分发（传模型的目录我已经加进 gitignore 里了）。

> ⚠️ 强调一下，为了规避版权风险，本发行版不附带任何其他模型文件，只带了这一个官方允许随便用的示例模型「桃濑日和」。

## 操作一览
<a id="操作一览"></a>

| 你要干嘛 | 它会有什么反应 |
| --- | --- |
| 单击立绘 | 戳一戳它，它会随机做一个动作或者换个表情 |
| 双击立绘 | 打开或者关上输入框；敲回车把话发出去 |
| 点左下角的箭头圆钮 | 也是打开/关上输入框（位置在气泡那个粉色点正下方） |
| 点输入栏左边的圆麦克风 | 语音输入：点一下开始录音，再点结束，认出字来自动发（要是按钮是灰的，说明服务没开或者挂了） |
| 拖着立绘不放 | 把它拖到屏幕任何地方 |
| 拖右下角那个半透明把手 | 放大缩小窗口和模型（它会记住你拉的大小） |
| 右键点它 | 调出菜单：聊天 / 换模型 / 点击穿透 / 设置 / 退出 |
| 按下 `Ctrl+Shift+P` | 开启/关闭点击穿透（要是你让它穿透了，鼠标就点不到它了，得靠快捷键或者右下角托盘图标切回来） |
| 点气泡头上的粉色点 / 直接点气泡 | 把气泡收起来（如果你不理它，它说完话 15 秒后自己也会收起） |
| 右下角托盘图标 | 找回丢失的它：切换穿透 / 或者直接退出 |

## 从源码自己编译（硬核玩家专区）
<a id="从源码构建"></a>

前提条件：电脑上得有 Node.js v20+、稳定的 Rust 环境（rustup）、VS 2022 Build Tools，还要有 Python 3。

```bash
git clone https://github.com/Koishi-Neko/astrbot_plugin_desktop_pet
cd astrbot_plugin_desktop_pet/pet_shell
npm install
npm run dev     # 第一次跑它会自动去拉 Live2D 的渲染库（如果你网络卡了，可以单独跑 npm run setup 多试几次）
npm run build   # 最终会产出一个独立的 exe：src-tauri/target/release/pet_shell.exe
```

> 为什么不直接把 Live2D 渲染库（pixi / pixi-live2d-display / Live2D Cubism Core）塞进仓库？因为许可协议不允许，所以我写了个 `tools/fetch_vendor.py` 脚本，跑的时候根据 SHA256 校验去下载。要是下载失败，检查一下你是不是没开代理，然后再跑一遍 `npm run setup`。
> 友情提示：`npm run dev` 编译出来的 debug 版 exe 如果你不带命令行直接双击，它会给你看个大白屏。想单双击运行，请乖乖去跑 `npm run build` 用 release 产物。

如果你想预设好配置发给别人用，可以在 `pet_shell/src/` 下面建个 `config.local.json`（我已经把它 gitignore 了；release 编译的时候会**直接把这个文件嵌进程序里**，所以**千万别在打包机上把自己的私钥放进去**，给别人用最好还是让他们自己去设置面板里填）：

```json
{
  "mode": "astrbot",
  "base_url": "http://localhost:6185",
  "api_key": "你的 API Key",
  "standalone": {
    "llm_base_url": "https://api.deepseek.com/v1",
    "llm_api_key": "你的模型 API Key",
    "llm_model": "deepseek-chat",
    "tts_url": "http://localhost:5000"

  "asr": {

  }
}
```

## 出了 Bug 怎么办（常见问题）
<a id="常见问题"></a>

- **桌宠装死不说话（AstrBot 模式）**：去设置面板点一下「测试连接」，看看哪个没过；去看看 AstrBot 的后台日志里有没有打印出 `[desktop_pet] web api registered`；你的 API Key 必须同时拥有 plugin 和 chat 权限（如果你想让它看桌面，还得加上 file 权限）。
- **桌宠装死不说话（独立模式）**：去设置面板切到独立模式，再点「测试连接」；模型地址最好老老实实写到 `/v1` 结尾（虽然你只写个根地址它也会尽量帮你补）；如果你连的是本地 Ollama，API Key 那个框不能空着，随便敲点什么进去都行。
- **独立模式下它像个金鱼，转头就忘了以前的事**：这就是 V1 版本的设计，没办法（不过这次聊天没关掉之前的话它还是记得的）；如果真想让它有长期记忆，乖乖回去用 AstrBot 模式吧——那边插件自己就内置了长期记忆，不用再装别的。
- **Live2D 根本不出来（自己跑源码的时候）**：去看看 `src/vendor/` 目录下是不是少了那三个 js 文件（跑一下 `npm run setup`）；如果你的模型路径里带了中文或者其他非 ASCII 字符，或者它根本不是 Cubism 3/4 的模型，那也是加载不出来的。
- **它是个哑巴，没声音**：控制页的 TTS 开关开了没？SBV2 的状态是不是「可达」？模型/说话人选了没？壳子自己设置里的「语音」开关开了没？——这三个地方都得搞好才行（如果你是独立模式，去设置面板里确认下 TTS 地址填对没）。
- **麦克风按钮是灰的 / 点了没反应**：去控制页「语音输入」那里看看开关开了没，或者是 ASR 服务还没准备好（第一次跑要加载大概 4 分钟呢，运行 `start_asr.vbs` 把它拉起来；如果你等了半天还是不行，把鼠标悬停在麦克风按钮上看看它报的什么错）。
- **语音识别出来的字全是错的**：目前我锁死了只能认中文；毕竟这是个跑在本地的 whisper 模型，你要是口音太重或者旁边太吵它也没办法，试着说慢一点。或者去控制页确认下，你填的那个识别服务地址是不是真的指向了你本地的 ASR 服务。
- **它回复了但是表情不变**：要是大模型没按要求把情绪标签输出出来，桌宠就会默认用「平静」表情兜底，这很正常；你可以在人格 prompt 里稍微威胁一下大模型，让它好好按格式说话。
- **我的 AstrBot 不在本机上**：去设置里把地址改成你对应的服务器 IP 就行了。API Key 就是你的通行证，**千万别把 6185 端口直接裸露到公网上**。
